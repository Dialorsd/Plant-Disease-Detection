# PlantGuard — Plant Disease Detection Using Deep Learning

## About the Project

PlantGuard is a deep learning project focused on identifying plant diseases from images of leaves using Convolutional Neural Networks (CNN).

The main goal of the project is to develop a web application that allows users to upload an image of a plant leaf and receive a prediction of its health condition.

The project uses the [PlantVillage dataset](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset) from Kaggle and is developed using Python, TensorFlow, Keras, and Streamlit.

## Project Objectives

The main objectives of this project are:

- Analyze and preprocess plant leaf images from the PlantVillage dataset.
- Develop and train a Convolutional Neural Network (CNN) for plant disease classification.
- Implement MobileNetV2 using transfer learning.
- Evaluate and compare the performance of different deep learning models.
- Develop a web application using Streamlit.
- Allow users to upload images of plant leaves for disease detection.
- Display predicted plant conditions and prediction confidence scores.
- Provide a simple and user-friendly interface for interacting with the trained model.
